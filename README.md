# Boss Tetris 玩家指南

一款「打王版俄羅斯方塊」的單頁網頁遊戲：一邊消行、一邊對 Boss 造成傷害，
還能用賽季積分解鎖裝飾與音樂，佈置屬於自己的小家。

本文件涵蓋：**怎麼玩**、**畫面與功能說明**、**存檔與資料**、以及給開發/測試者看的
**Debug Console 使用說明**。

---

## 1. 快速開始

1. 用瀏覽器打開 `index.html`（手機或電腦皆可，直向畫面體驗最佳）。
2. 首次進入會看到「首頁」畫面，下方有 4 顆導覽按鈕：**關卡 / 任務 / 布置 / 設定**。
3. 點「關卡」→「開始」即可進入戰鬥；點「任務」可查看每日任務、挑戰任務與積分獎勵；
   點「布置」可以把解鎖到的素材拖曳擺放到首頁；點「設定」可以調整音量、匯出/匯入存檔。

> 遊戲會自動存檔在瀏覽器的 IndexedDB 中，不需要登入帳號，但也代表**換瀏覽器、換裝置、
> 清除瀏覽器資料都會遺失進度**，重要進度建議定期到「設定」→「匯出存檔」備份一份 JSON 檔。

---

## 2. 首頁（布置畫布）

- 中間的大畫布是你的「家」，可以放背景、植物、食物、角色等裝飾。
- 右下角的黑色唱片機 🎵：點一下會跳出已解鎖歌曲清單，可以選歌播放或停止播放。
  唱片機在音樂播放中會旋轉。
- 左上角「✏️ 布置模式」：切到「開啟」後，畫布上的物件可以拖曳移動、也會跳出
  小工具列（旋轉 / 翻轉 / 縮放 / 上移一層 / 移除）。
- 布置模式關閉時，畫布只作展示用，不能拖動物件。

---

## 3. 關卡與戰鬥（打 Boss）

### 3.1 進入戰鬥
- 「關卡」畫面顯示 Boss 圖片、血條與目前體力（🔋 stamina，每次挑戰消耗 1 點，
  體力會隨時間自動恢復，上限與恢復速度可在原始碼 `CONFIG.stamina` 調整）。
- 體力足夠時按「開始」進入戰鬥畫面。

### 3.2 戰鬥畫面操作
| 按鈕 | 功能 |
|---|---|
| ◀ / ▶ | 方塊左右移動 |
| ↻ | 方塊旋轉 |
| ▼ | 加速下降（按住連續加速，符合一般俄羅斯方塊手感） |
| 右上角 ✕ | 離開戰鬥，回到首頁 |

- 畫面右側會顯示 Boss 目前血量、以及接下來 2 個方塊的預覽（NEXT）。
- **消行 = 攻擊 Boss**：消除的行數愈多、連續消行的 combo 愈高，造成的傷害愈高
  （對應 `CONFIG.damage` 與連段加成 `comboStepPct` / `comboMaxMult`）。
- 把 Boss 血量打到 0 即獲勝，畫面會顯示過關時間與最大連段數；
  若方塊堆到畫面頂端（無法再生成新方塊）則遊戲失敗。

### 3.3 Boss 技能（垃圾列 / 炸彈方塊）
- Boss 每隔一段時間（預設 20 秒，`CONFIG.boss.attackIntervalMs`）會施放技能：
  畫面會先播放 Boss 撲向你的動畫，接著在棋盤**最底部新增一整排「垃圾列」**，
  並把你原本的堆疊往上推。
- **這一排垃圾列裡只會有「一個」隨機位置的炸彈方塊 💣，其餘都是一般垃圾方塊**
  （深灰色、沒有圖案），這點對齊了《Tetris Battle》的規則：
  - 一般垃圾方塊：不能單靠疊滿整排消除，必須讓玩家自己消掉上面的行，
    垃圾列才會跟著往上推進、最終被推出畫面，或是……
  - 炸彈方塊：只要你正常下落的方塊**壓到／貼到**炸彈方塊所在的格子
    （方塊的任一格與炸彈方塊上下左右相鄰），就會立刻引爆，
    **把炸彈所在的那一整排直接清除**，不需要湊滿整排。
- 只要不被方塊堆滿畫面頂端，垃圾列本身不會直接扣血，但會擠壓你的操作空間，
  所以看到炸彈方塊時，故意把方塊蓋上去清掉它是常見的解法。

## 4. 任務與積分（賽季系統）

- 遊戲以「賽季」為單位輪替（預設每輪 14 天，`CONFIG.seasonLengthDays`），
  每輪有各自的積分獎勵清單（背景 / 植物 / 食物 / 角色 / 音樂）。
- **每日任務**：完成一場戰鬥、或是在戰鬥中成功消除任意一行，各可領取積分
  （`CONFIG.dailyTaskPoints`，預設 10 分），每天重置。
- **挑戰任務**：本賽季累積勝場數達到門檻（預設 10 / 20 / 30 勝）可各領取一次積分。
- **積分獎勵軌道**：賽季累積積分達到門檻即可領取對應素材（含最後一項通常是「音樂」），
  領取後的素材會自動加入「布置」清單、音樂則會出現在唱片機的歌曲清單中。
- 積分只在該賽季內累計，賽季更換後會歸零並換一批新的獎勵清單。

## 5. 布置與設定

- **布置**：分類頁籤（背景 / 植物 / 食物 / 人物 / 其他），已解鎖的素材可直接點擊放到首頁，
  背景類會鋪滿整個畫布，其餘類別會隨機出現在畫布中央附近，之後可在「布置模式」拖曳調整。
- **設定**：
  - 音樂音量 / 音效音量：即時調整，會自動存檔。
  - 音樂開關：關閉後音樂會靜音（但不會暫停播放進度），方便你之後再打開時銜接播放。
  - 匯出存檔：下載目前進度成 `boss_tetris_save.json`。
  - 匯入存檔：讀取先前匯出的 JSON 檔還原進度。
  - 清除所有資料：清空本機存檔，回到全新遊戲狀態（此動作無法復原，會有二次確認）。

## 6. 音樂播放行為說明

音樂使用瀏覽器單一個 `<audio>` 元素播放，**整個網頁生命週期只建立一次**，
切換首頁／關卡／任務／布置／設定畫面，或是點擊任何按鈕，都只是 CSS 顯示/隱藏對應畫面，
**不會重新建立或重新 `play()`** 這個 `<audio>` 元素，所以：

- 播放中切換畫面、點擊任何按鈕、Boss 施放技能動畫、消行特效等，都不會讓音樂從頭重播。
- 只有在你「主動換另一首歌」或「按下停止播放」時，音樂才會重新開始 / 停止。
- 若瀏覽器因自動播放限制而擋下第一次播放，遊戲會在你下一次點擊畫面任何地方時
  自動嘗試接續播放（`unlockOnGesture`），同樣不會從頭重播已經播放過的進度。

## 7. Debug Console（測試用，僅供開發/測試者使用）

為了方便直接測試「積分 250」與「第一輪所有素材（含音樂）全部解鎖」後的布置與音樂功能，
遊戲內建了一個掛在 `window.Debug` 上的除錯工具，**不會出現在正式 UI 裡**，
需要打開瀏覽器開發者工具的 Console 分頁手動輸入指令：

1. 打開遊戲（`index.html`）。
2. 打開瀏覽器開發者工具（Chrome/Edge：F12 或右鍵「檢查」→ Console 分頁；
   Safari 需先在「偏好設定→進階」開啟「顯示開發選單」）。
3. 等頁面完全載入（能看到首頁）後，在 Console 輸入以下指令並按 Enter：

```js
Debug.unlockRound1();
```

執行後會：
- 把目前賽季積分設為 **250**（可傳入自訂數字，例如 `Debug.unlockRound1(500)`）。
- 把「第一輪」的全部素材（背景 / 植物 / 食物 / 角色 / 音樂）標記為已解鎖，
  加入到你的「布置」清單與唱片機的歌曲清單中。
- 畫面會跳出提示 toast，並自動刷新目前開啟中的畫面（首頁 / 任務 / 布置皆會即時反映）。

其他可用指令：

```js
Debug.addPoints(30);   // 目前賽季積分 +30（可測試積分獎勵軌道的即時刷新）
Debug.state();         // 在 Console 印出目前完整存檔物件，方便檢查資料結構
```

測試完成後，可以到「設定」→「清除所有資料」把測試用的存檔清掉，
或是「匯出存檔」備份/切換測試情境。

> 這個 Debug 工具只是直接修改本機存檔物件（等同正常解鎖流程的最終結果），
> 不會影響遊戲本身的積分規則或正式上線邏輯；正式發布前若不想保留這個入口，
> 可以直接刪除原始碼中「DEBUG CONSOLE」整段程式碼區塊。

## 8. 給維護者的補充說明（本次修改重點）

- `pushGarbageRows()`：Boss 技能新增的垃圾列，現在每排只會產生 **1 個隨機位置的
  炸彈方塊**，其餘為一般垃圾方塊；炸彈觸發判定（`checkBombTouch` / `explodeBombRow`）
  沿用原本「方塊上下左右貼到炸彈即整排清除」的邏輯，未變動。
- 已交叉比對過角色、任務、布置、設定、存檔、音樂系統等既有函式，確認本次修改
  沒有覆蓋或影響到其他既有功能（消行判定、傷害計算、體力/每日/賽季重算、
  匯入匯出、清除資料等皆維持原行為）。
- 音樂播放邏輯本身在修改前即已採「單一持久化 `<audio>` 元素 + 畫面純 CSS 切換」設計，
  已確認任何按鍵點擊、畫面切換、Boss 技能動畫、visibilitychange（切分頁/背景）
  都不會觸發音樂重新載入或從頭播放，此次未變動、僅在本文件第 6 節做說明存檔。
- 新增的 `window.Debug` 工具全部包在原本的 IIFE 內，僅新增，未修改任何既有函式簽名，
  所有呼叫都對 `STATE` 尚未載入的情況做了保護（避免頁面剛打開就在 Console 呼叫報錯）。
